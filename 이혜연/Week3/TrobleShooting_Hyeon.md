### 1. Mission: 공인중개사 시험 합격 판별 사이트

#### 문제 상황

- 두 과목의 합계가 120점 미만인 경우에도 불합격이 아닌 **합격** 알람이 발생하는 현상 발생

#### 원인 분석

- 두 과목 점수의 합이 숫자의 합이 아닌 문자열의 합으로 인식되는 것으로 추정
- console.log를 이용하여 확인한 결과, 문자열의 합으로 인식되고 있음을 확인했음
  - 예: 점수가 각각 60, 40인 경우, `60 + 40 = 100`이 아니라 `"60" + "40" = "6040"`으로 처리됨.
  - 결과적으로 `"6040" >= 120` 이므로 잘못된 합격 판정이 내려짐

#### 해결 방법

- `Number()` 함수를 사용하여 문자열 형태로 들어온 입력값을 **숫자 타입으로 변환**하여 산술 연산하도록 함

### 2. Task: 명함 제작 사이트

#### 문제 상황

- 프로필 사진 첨부 여부에 따라 명함 아바타 영역을 다르게 표시해야 했음
  - 사진이 있을 때: 이미지를 원형으로 표시
  - 사진이 없을 때: 포인트 컬러 배경 + 이름 텍스트 표시

#### 원인 분석

- `<input type="file">`로 받은 파일은 바로 `src`나 `url()`에 사용할 수 있는 형태가 아님
- CSS의 `background-image`에 직접 파일 객체를 넣을 수 없음

#### 해결 방법

- `URL.createObjectURL()`을 사용해 로컬 파일 객체를 브라우저가 인식할 수 있는 임시 URL로 변환 -`URL.createObjectURL()`: 로컬 파일을 브라우저가 사용할 수 있는 임시 주소로 만들어주는 함수
- 변환된 URL을 CSS 변수 `--profile-url`에 넣어 CSS의 `background-image`에 적용
  - `background-image`는 `background-color` 위로 보여지기 때문에 이미지가 있을 때는 이미지가 컬러를 덮고 없을 때는 컬러만 보임
- `if`문을 사용하여 입력된 사진이 없을 경우 포인트 색상의 원 위에 이름 텍스트 보이도록 처리
